## ⚖️ POINTS DE DROIT

### Principes Juridiques Posés

#### 1. Formalités Substantielles Obligatoires
**Texte:** "Le non accomplissement des formalités substantielles prévues par la loi prive le licenciement de cause réelle et sérieuse et le rend par conséquent abusif"

**Formalités requises (Article 45-46):**
- Lettre écrite de licenciement
- Motif objectif et sérieux
- Délai de préavis (Article 53)

**Conséquence:** Absence même UNE formalité = licenciement abusif

#### 2. Défense de l'Employeur par Absence
**Principe:** "L'employeur qui n'a produit aucun moyen de défense et s'est abstenu de se défendre bien qu'ayant été dûment convoqué → licenciement abusif présumé"

**Logique:** Silence = acceptation implicite de l'abus

**Application:** Tribunal suppose licenciement abusif sauf preuve contraire employeur

#### 3. Salaire Inférieur au SMIG - Aggravant
**Disposition:** Article 243 Code du Travail (salaire minimum garanti)

**Violation:** Employer paid 20,000 FCFA for 7+ years (certainement < SMIG)

**Conséquence:** Non-paiement du minimum légal = dommage supplémentaire

#### 4. Défaut de Déclaration OBSS
**Obligation légale:** Employer must register all workers with OBSS (security social)

**Faits:** ASSEF used Séraphine's services 7 ans 3 mois sans déclaration

**Conséquence:** "Privée par le fait de son employeur du bénéfice des allocations dues"

**Dommages:** Droit à indemnité compensation (500,000 F accordée)

#### 5. Indemnité Congés Payés - Prorata
**Cadre:** Article 160 (droit après 1 an) + Article 163 (indemnité rupture)

**Règle:** "Indemnité compensatrice congés calculée au prorata de la période passée"

**Application:** 7 ans 3 mois × 2 jours/mois = 174 jours congés acquis  
Indemnité = 200,292 F (selon jugement)

#### 6. Dommages-Intérêts Modérés par Tribunal
**Demandé:** 7,000,000 F  
**Accordé:** 1,000,000 F  
**Justification:** "Somme réclamée exagérée... il échet cependant de réduire le montant"

## 📊 ANALYSE CALCULATOIRE

### Calcul Indemnité Licenciement
**Service:** 7 années 3 mois 6 jours = 7.26 années  
**Salaire:** 20,000 FCFA/mois (définivement < SMIG)  
**Indemnité accordée:** 53,212 F

**Calcul implicite:**
```
53,212 F ÷ 20,000 FCFA = 2.66 mois de salaire
Taux = 2.66 ÷ 7.26 = 0.366 = 36.6% par année

Observations:
- Proche de taux 35% que code implémente!
- Légèrement au-dessus pour 7+ années
- Suggère graduation: 30% (1-5) → 35-40% (6+)
```

**Note critique:** Service exclus du 1er avril 1997 (compté depuis embauche, pas après 1 an)

### Calcul Indemnité Congés Payés
**Données:**
- Service: 7 ans 3 mois 6 jours  
- Accumulation: 2 jours/mois × ~87 mois = 174 jours
- Montant accordé: 200,292 F

**Diviseur implicite:**
```
Salaire/jour = Indemnité / Jours Congés = 200,292 / 174 = 1,152 FCFA/jour
Salaire/mois = 20,000 FCFA
Diviseur = 20,000 / 1,152 = 17.36 (bizarre!)

Alternative diviseur:
Si diviseur = 26: Daily = 20,000/26 = 769 FCFA → Indemnité = 769 × 174 = 134,000 F (pas 200K)
Si diviseur = 30: Daily = 20,000/30 = 667 FCFA → Indemnité = 667 × 174 = 116,000 F (pas 200K)

Possible:
Tribunal utilise autre formule (peut-être prorata mois entiers)
200,292 / 20,000 = 10 mois équivalent pour 7 années
Taux = 10 / 7.26 = 1.38 mois/an congés
Ou = 2 jours × 7.26 × calcul complexe
```

**Conclusion:** Diviseur non transparent - ne peut pas valider 26 vs 30

### Indemnité Préavis
**Montant accordé:** 27,500 F  
**Salaire:** 20,000 FCFA

**Calcul:**
```
Préavis obligatoire = 1 mois (ouvrier/employé standard)
Indemnité = 27,500 ÷ 20,000 = 1.375 mois
Fractions = 27,500 / 20,000 × 30 jours = ~40 jours (légèrement > 1 mois)

Possible:
Indemnité = Salaire × (33 jours / 30) = 20,000 × 1.1 = 22,000 (pas 27,500)
Indemnité = Salaire × 1.375 mois = 20,000 × 1.375 = 27,500 ✓

Donc: ~1.375 mois de préavis calculé (41 jours sur 30)
```

### Moins-Perçus SMIG
**Accordé:** 364,840 F pour 7 ans 3 mois  
**Salaire reçu:** 20,000 FCFA/mois  
**SMIG légal (estimé):** ~?? FCFA

**Calcul inverse:**
```
Total mois = 87 mois
Moins perçu/mois = 364,840 / 87 = 4,194 FCFA/mois
SMIG = 20,000 + 4,194 = 24,194 FCFA (estimé)

Plausibilité: Bénin 2004 → SMIG ~25K possible
```

### Dommages OBSS (Sécurité Sociale)
**Accordé:** 500,000 F  
**Service:** 7 ans 3 mois

**Logique:** Cotisations non versées + allocations perdues = 500K total  
**Taux:**500,000 / 87 mois = 5,747 FCFA/mois équivalent  
**Probable:** Estimation allocations + cotisations non versées

### Dommages Licenciement Abusif
**Demandé:** 7,000,000 F  
**Accordé:** 1,000,000 F  
**Réduction:** 86% (jugement find "excessive")

**Facteurs appliqués:**
- ✅ Licenciement abusif établi (sans formalités)
- ✅ 7 années d'ancienneté (factor important)
- ✅ Salaire inférieur SMIG (aggravant)
- ✅ OBSS non-déclaration (aggravant)
- ✅ Précarité réelle (travailleur femme?)

**Facteurs NOT appliqués:**
- ❌ Demande "exagérée" de 7M → réduit à 1M
- ❌ Court trouve 1M = "juste proportion"

## 📚 LEÇONS JURISPRUDENTIELLES

### 1. Défaut de Formalité = Licenciement Abusif Automatique
**Règle:** Même une formalité manquante (lettre, motif, préavis) = abusif  
**Implication:** Code MUST verify toutes 3 formalités

### 2. Salaire Inférieur SMIG = Dommage Supplémentaire
**Evidence:** ASSEF condamné 364,840 F pour moins-perçus  
**Implication:** Code doit checker SMIG vs salaire contractuel

### 3. OBSS Non-Déclaration = Dommage Automatique
**Evidence:** 500,000 F accordée sans détail  
**Implication:** Code doit intégrer vérification déclaration sécurité sociale

### 4. Indemnités Convergeant vers Taux Standard
**Données:** 
- Cas #001 (2.6 ans): 327,083 F
- Cas #002 (12.3 ans): 497,156 F  
- Cas #003 (7.3 ans): 53,212 F

**Pattern:** Taux graduels apparent (30/35/40) non linéaires

### 5. Indemnité Préavis ≈ 1-1.4 mois Salaire
**Evidence:** 27,500 F / 20,000 FCFA = 1.375 mois  
**Implication:** Formule = Salaire × (40 jours / 30)
